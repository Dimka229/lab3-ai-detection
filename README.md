# Лабораторная работа №3: Детекция объектов на изображениях

**Дисциплина:** Прикладные задачи искусственного интеллекта
**Вариант:** 1 — Контроль касок на стройплощадке

## Описание задачи
Цель работы — построить детектор строительных касок (helmet) и голов без касок (head) на изображениях. 
Модель должна в реальном времени определять наличие средств индивидуальной защиты для предотвращения несчастных случаев.

## Данные
Использован публичный датасет **Hard Hat Sample** (Roboflow). 
*   Объем: 485 изображений (разбиты на train/val/test).
*   Классы: `helmet`, `head`.

## Обучение
Обучены две модели семейства YOLOv8 с использованием предобученных весов (transfer learning):
1.  **YOLOv8n** (маленькая) — 15 эпох, img_size=640.
2.  **YOLOv8s** (средняя) — 15 эпох, img_size=640.

## Результаты (на тестовой выборке)
| Модель | mAP@0.5 | mAP@0.5:0.95 | Скорость (GPU) | Размер |
| :--- | :--- | :--- | :--- | :--- |
| **YOLOv8n** | **0.850** | **0.466** | **10.5 мс** | 6.2 МБ |
| YOLOv8s | 0.834 | 0.448 | 13.9 мс | 22.5 МБ |

**Вывод:** Модель YOLOv8n показала лучшее качество и скорость на данном датасете. Она выбрана для эксплуатации.

## Экспорт и сервис
*   Лучшая модель экспортирована в формат **ONNX** (`best.onnx`, 12.2 МБ).
*   В сервис (FastAPI) добавлен эндпоинт **`/detect`**, который принимает изображение и возвращает JSON с координатами рамок, классами и уверенностью.
